# PhotoVote

Статическое веб-приложение для визуального просмотра и субъективной оценки фото. Работает полностью в браузере: файлы не загружаются на сервер.

Подходит для публикации на **GitHub Pages** — сборка бэкенда не нужна.

## Возможности

- Drag-and-drop папки или нескольких файлов, выбор через системный диалог
- Форматы фото: PNG, JPG, WebP, GIF, BMP, AVIF, TIFF — любого разрешения (до 64 Мп)
- File System Access API в Chromium (с деградацией в остальных браузерах)
- **2D-просмотр без 3D**: фото вписывается в рамку без растяжения (contain);
  перемещение — ЛКМ/один палец, масштаб — колесо, pinch на тач-устройствах,
  двойной клик — быстрый зум, кнопки −/%/+/вписать и клавиши `+` `−` `0` и стрелки
- **Фон под фото**: по умолчанию (градиент темы), белый, чёрный или свой цвет —
  системная пипетка, ползунки HSV и поле HEX; меняется мгновенно и запоминается
  в браузере. Переключается в настройках слева или кнопкой **Фон** над окном
  просмотра, действует на оценку, тейбрейкер и детальный просмотр
- Шесть категорий по шкале 1–10: причёска, цвет глаз, верхняя одежда,
  нижняя одежда, обувь, аксессуары
- Итог как среднее с округлением до одного знака
- Тейбрейкер: при равных итоговых баллах фото в топ-8 попарно сравниваются
  пользователем («какое лучше?») — это определяет только порядок, оценки не меняются
- Таблица лидеров с превью фото в каждой строке, подиум топ-3, детальное
  fullscreen-просмотр с тем же 2D-управлением
- Кнопка папки показывает полный путь к файлу и папке с возможностью копирования
  (браузер не может открыть системный проводник и выделить файл)
- Экспорт оценок в `.json` и импорт ранее сохранённой сессии (с превью)

## Запуск локально

Откройте папку любым статическим сервером, например:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.

Либо просто опубликуйте репозиторий через GitHub Pages (Source: Deploy from a branch → `/` root).

## Как пользоваться

1. Перетащите папку с фото или выберите файлы.
2. Проверьте список валидных фото и уберите лишнее.
3. Нажмите **Начать** — порядок перемешается один раз.
4. Осмотрите фото: перемещайте и масштабируйте, оцените все шесть категорий, затем **Следующий**.
   Если детали сливаются с подложкой — поменяйте **Фон фото** (настройки слева или
   кнопка **Фон** над окном просмотра): белый, чёрный или свой цвет.
5. После последнего фото при наличии ничьих в топ-8 откроется экран **тейбрейкера**
   — выберите лучшее фото в каждой паре. Затем — таблица лидеров.
6. На таблице лидеров можно **Сохранить оценки** в `.json`, а на экране загрузки —
   **Загрузить оценки** из ранее сохранённого файла и сразу посмотреть результат.

Прием фото: любой из поддерживаемых форматов и любое разрешение до 64 мегапикселей.
Большие файлы отклоняются с указанием причины — это защита вкладки браузера
от исчерпания памяти при декодировании битмапа.

## Категории оценки

| Категория | Что оценивается |
|---|---|
| Причёска | форма, укладка и подача волос, их соответствие персонажу |
| Цвет глаз | выбор оттенка и его гармоничность с общим образом |
| Верхняя одежда | жакет, рубашка, верхняя одежда: стиль, посадка и сочетание |
| Нижняя одежда | брюки, юбка: крой, цвет и сочетание с верхом |
| Обувь | тип и стиль обуви, уместность и гармония с нарядом |
| Аксессуары | украшения, сумки, головные уборы и прочие детали образа |

## Фон под фото

Подложка за оцениваемым фото — отдельная настройка просмотра: на оценки,
порядок фото и таблицу лидеров она не влияет.

| Вариант | Что делает |
|---|---|
| По умолчанию | градиент темы, как было до появления настройки |
| Белый | чисто белая подложка `#FFFFFF` |
| Чёрный | чисто чёрная подложка `#000000` |
| Свой цвет | любой цвет: системная пипетка, ползунки HSV (H 0–360, S и V 0–100), поле HEX и быстрые цвета |

Цвет в режиме «Свой цвет» применяется сразу — без кнопок «Применить»: ведёте
ползунок или печатаете HEX, фон меняется на ходу. Неполный или неверный HEX
(`#12f4`) подсвечивается ошибкой и фон не трогает; принимаются `#rgb`, `rgb`,
`#rrggbb` и `rrggbb`.

Выбор хранится в `localStorage` и переживает перезагрузку, а при сохранении
сессии в `.json` записывается вместе с оценками — после загрузки файла фото
откроются на том же фоне. На светлой подложке подписи поверх сцены и чип
масштаба автоматически переключаются на тёмные, чтобы оставаться читаемыми.

## Структура

```
index.html            разметка всех экранов (загрузка, оценка, таблица, тейбрейкер)
css/app.css           тема и стили
js/app.js             состояние сессии, экраны, сортировка/фильтры, экспорт/импорт
js/viewer.js          2D-вьюер фото (перенос + масштаб) и генератор миниатюр
js/files.js           выбор файлов, drag-and-drop, валидация форматов и размера
js/categories.js      единый источник категорий (карточки, таблица, фильтры, JSON)
js/backdrop.js        состояние фона под фото (режим + цвет), хранение и применение к сценам
js/backdrop-ui.js     контрол фона: четыре режима, пипетка, ползунки HSV, поле HEX
```

## Ограничения

- Всё работает в памяти вкладки: при перезагрузке страницы сессия теряется,
  если оценки не сохранены в JSON.
- Изображение никогда не деформируется: только вписывание (contain), перенос
  и равномерный масштаб.
- Фон — это только подложка сцены просмотра: сами файлы и превью в таблице
  лидеров не перерисовываются.
